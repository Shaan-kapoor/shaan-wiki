Make vault.json

This encrypts your GitHub token with your password so it can be committed to a public repo safely. Everything happens in this page — nothing is uploaded, and the token never leaves your machine. Open this file locally, not from the live site.

The password is the only thing protecting the token. The encrypted blob will be public, so a weak password can be cracked offline at leisure. Use four random words — something like rope-candle-vertigo-plum. Not a password you use elsewhere.

Making the token

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access: only Shaan-kapoor/shaan-wiki
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Expiry: the maximum, 366 days. That outlives the domain by one day, so you will never have to rotate it.
  5. Paste it above, encrypt, save the output as data/vault.json, commit.
